File explorer for Windows, macOS and Linux

Move fast. Never wait.

Soyuz is a keyboard-first file explorer built in Rust for speed and reliability. Every copy, move and delete runs as a background job you can pause, cancel and undo, so the interface stays instant even when a network share does not.

Engineered to be dependable

Soyuz takes its name from the spacecraft that has flown for decades by being simple and reliable. Eight principles shape every part of the app.

  • Keyboard-first

    Every action is in the command palette with its shortcut, and every shortcut can be rebound. Start from the Explorer, Commander, Finder or Vim preset and make it your own.

  • Never blocks

    Listings, previews, thumbnails and all disk access run off the interface thread. Folders stream in as they are read, and a slow drive never freezes the window.

  • Every operation is a job

    Copy, move, delete, extract and checksum show real progress. Pause, resume or cancel any job, and decide exactly what happens when names collide.

  • Trash first, then undo

    Deleted files go to the trash by default. Copies, moves, renames, new items and archive edits can all be undone and redone.

  • No shell backend

    Soyuz works with the file system and the kernel directly, never through the Windows shell, Finder or a desktop file layer. Behaviour is predictable, cancellable and consistent on every machine.

  • Fully configurable

    Every behaviour has a setting, in the Settings window and in a single config.toml. Edit the file in any editor and Soyuz applies it within a second, comments intact.

  • Private by default

    No telemetry, no accounts, no ads. Soyuz checks for updates only when you ask it to.

  • Open source

    Written in Rust and MIT licensed. Read the code, build it with stable Rust and contribute.

A tour of the cockpit

Everything shown here ships today on Windows, macOS and Linux. Most of it is a single shortcut away.

Two panes, or four

Work side by side in dual panes, or split the window into a 2×2 grid. Copy or move to the other pane with a single key. Tabs support groups, pinning and tear-off windows, and any layout can be saved as a workspace.

Look before you open

Quick Look and the preview pane display images, syntax-highlighted code, Markdown, PDF pages, Office documents, EPUB, fonts, 3D models, audio with waveform and playback, video frames, binaries in hex and side-by-side diffs. Archives open just like folders.

Space Quick LookAltP preview pane

Every action, one search away

The command palette finds any action by name and shows its shortcut, so you learn the keys as you work. Go to folder takes you to the places you visit most. Bind anything, including chords and two-key sequences like g g.

CtrlK command paletteCtrlP go to folder

Jobs you can steer

The activity panel shows every job with its speed, a live graph and the time remaining. Jobs queue per drive, so two copies to the same disk never compete. Conflicts open a side-by-side comparison, and after a crash or power cut, unfinished jobs resume exactly where they stopped.

CtrlShiftJ activity panelCtrlZ undo

A terminal that follows you

Your own shell, docked below the file list and always in the current folder. It works both ways: cd somewhere and the file list follows. Ctrl-click opens paths and links.

Ctrl` terminal

Find out where the space went

The disk-usage treemap shows folders by size; click to zoom in. Compare two folders and sync them one way or both ways, with saved and scheduled profiles. Find duplicates by size and content, and send the extra copies to the trash.

Make it yours

Details, list, thumbnail grid, gallery and Miller columns, remembered for each folder. Five color themes (Orbit, Nord, Solarized, Rosé Pine and High Contrast), each in dark and light, plus your own theme files and the system accent color. The interface is available in English and Turkish and switches instantly.

Ctrl, settings

The same explorer in a terminal

Run soyuz --tui over SSH or in any terminal and get the same panes, tabs, jobs, palette and tools, with the keyboard and the mouse. It shares your settings and bookmarks with the window, and a screen-reader mode reads one plain line at a time.

soyuz --tui terminal UI--screen-reader screen-reader mode

Also on board

The tools you would otherwise install separately, built in and working together.

Search and the index

Search file names and contents with a compact query language. Enable the background index and searches across all your folders return in milliseconds. Save any query as a smart folder that keeps itself up to date.

kind:image size:>5MB modified:<7d -draft

Remote locations

SFTP, WebDAV, FTP and FTPS, S3-compatible storage and SMB network shares, with cached listings. Transfers between any of them are ordinary, resumable jobs.

Archives as folders

Browse zip, 7z, tar, RAR, ISO, CAB, deb and rpm without extracting them. Create and extract archives, including password-protected ones, and edit zip files in place.

Tags and folder colors

Eight color tags that stay with files as you move and rename them in Soyuz, folder colors and emblems, a drop shelf for gathering files, and a git status column.

Built-in editors

A text editor with syntax highlighting and regex find and replace, a hex editor for files of any size, and an image editor for quick crops and rotations.

Scripts and automations

Sandboxed Rhai scripts add actions, menu entries, columns and previewers. Folder rules move, rename or tag new files automatically. Every change asks for approval and can be undone.

Command line

soyuz cp, mv, rm and more queue jobs in the open window, with progress and conflict prompts shown there, or run directly in the terminal.

Accessible

Screen-reader support, a high-contrast theme, reduced motion, large touch targets, interface zoom and a visible focus indicator everywhere.

An assistant that asks first

Optional and off by default. Bring your own key for Anthropic, OpenAI or Gemini, or run a local model through Ollama, LM Studio, llama.cpp or vLLM. The assistant never touches your files directly: it proposes, you decide.

  1. Ask in plain words

    “Move last month’s invoices into a folder per client.”

  2. Review the plan

    You receive a dry run listing every move, rename and delete it would make, before anything happens.

  3. Approve, and it runs as a job

    The approved plan runs like any other job, with conflict handling and full undo.

  • API keys stay in the operating system’s credential store, never in the config file.
  • Per-folder permissions decide what may be shared with a cloud model. File names and contents are treated as untrusted data.
  • An MCP server lets other assistants drive Soyuz under the same approval rules, and an audit log records what they did.

Native builds for Windows, macOS and Linux, free of charge. Every release file is published with a SHA-256 checksum.

Platforms

Windows 10 and 11 x64
Supported Installer or portable zip, with Mica, Snap Layouts and the system accent color.
macOS Apple silicon
Supported Keychain, Finder clipboard, LaunchServices and Time Machine integration.
Linux x64
Supported Wayland and X11, freedesktop trash and thumbnails, UDisks2 drives and Secret Service.

Pick a package

  • Windows installer (.msi) Installs for your user account; no administrator rights needed.
  • Windows zip Unzip anywhere and run soyuz.exe. The portable edition keeps its settings beside the app, ideal for USB drives.
  • macOS (.tar.gz) For Apple silicon Macs. Unpack and run soyuz.
  • Linux (.tar.gz) Unpack anywhere and run soyuz.

Release builds are not code-signed yet. On first launch, Windows SmartScreen may ask for confirmation (More info, then Run anyway), and macOS asks once as well (right-click, then Open).
